# 设计实现

视觉来源为下载目录中 01–07 开头的七个 ZIP，完整解压到 `design/reference/01` 至 `07`。原始 HTML、支持文件和 vendor 文件保持原样，不进入生产扩展。

| 设计稿                         | 实现                                                                                                     |
| ------------------------------ | -------------------------------------------------------------------------------------------------------- |
| 01 空闲 · 白天                 | 暖白底、低对比慢速背景，空闲时隐藏全部控件                                                               |
| 02 空闲 · 黑夜                 | 深色背景及相同的空闲逻辑                                                                                 |
| 03 鼠标移到下部 · 按钮浮现     | 底部居中常用书签与全部书签双按钮胶囊，距底 36 px；左下角独立设置按钮，34 px 按钮、4 px 内边距、2 px 间距 |
| 04 悬浮星标 · 展开常用书签     | 星标悬停 140 ms 后展开常用书签，使用已保存的收藏顺序                                                     |
| 05 全部书签 · 级联悬浮菜单     | 书签栏内容为一级，非空其他根文件夹置末尾，递归悬浮菜单、目录计数与边缘避让                               |
| 06 设置 · 常用书签、背景与外观 | 960 × 640 双栏玻璃面板，收藏搜索/增删/排序，上限 10，效果选择、随机池、主题与隐藏延迟                    |
| 07 组件与内置效果 · 白天 黑夜  | 日夜材质、36 px 书签图标、默认/悬浮/激活状态、背景选择与扩展效果                                         |

日间底色 `#ECE9E1`，文字 `#1F1E1B`，玻璃白色 42%，边框白色 75%。夜间底色 `#0F1013`，文字 `#F4F2EC`，玻璃深色 50%，边框白色 16%。面板包含模糊、饱和度、边缘高光、阴影和静态颗粒。字体使用本地 Space Grotesk，中文使用系统无衬线字体。

控件只在三种情况下唤醒：鼠标在页面下部 30%（至少 160 px）内移动、按下鼠标或触摸、按键。鼠标在上部移动（例如移向标签栏或地址栏）不会唤醒。

胶囊使用两个图标按钮。鼠标在按钮上停留 140 ms 才展开弹层，鼠标只是经过底部（例如移向 macOS Dock）时不会打开；已有弹层打开时，移到另一个按钮立即切换。键盘操作时显示控件并保留焦点，鼠标离开弹层后关闭；悬浮跨越菜单间隙有延迟容错。窄屏导航保持居中并距底 40 px，设置距左 24 px，来源胶囊位于右下方第二行以避免重叠，设置转为单列纵向滚动，菜单按可用空间翻转。

常用书签有两种布局，存于 `preference:v1:favoritesLayout`：`tray` 收在星标后的托盘里（即上面的双按钮胶囊），`dock` 平铺在底栏。平铺时最多 10 个站点图标按收藏顺序直接排进液态玻璃胶囊，细分隔线之后是全部书签按钮；标题显示在图标上方的提示框（悬停约 220 ms 或键盘聚焦时出现）和 `aria-label` 中，点击行为与托盘相同。Tab 逐个经过图标，左右方向键、Home、End 也可移动焦点。空闲淡出与托盘模式一致。没有收藏时仍显示星标和空托盘；窗口宽度不足（图标数加一乘 36 px，再加两侧各 300 px 留给设置按钮和来源胶囊）时也退回星标托盘。读取到未知值或旧版本没有该键时按 `tray` 处理，老用户保持原样；新用户由首次引导选择，设置的常用书签栏也可切换。

全新安装时（没有任何偏好和收藏键）底栏上方显示两步引导卡片，使用磨砂 `GlassPanel`，不用液态玻璃。第一步用两张小示意图选择“平铺在底栏”或“收在星标里”，默认选中平铺；点继续保存布局。已有收藏时引导到此结束；没有收藏时进入第二步，展示书签栏里的前几个网页（最多 10 个）的图标，可一键添加为收藏，或选“稍后在设置里选”。书签栏没有网页时只显示说明和“知道了”。第一步的“跳过”只结束引导，不改布局（仍为 `tray`）。打开底栏弹层或设置时卡片暂时隐藏，保留当前步骤。完成或跳过后 `onboarding` 置为 false，不再出现。

## 背景

| 效果            | 图形与运动                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------------- |
| Grain Gradient  | Paper Shaders 的颗粒渐变，持续流动并随鼠标偏移                                                 |
| Shader Gradient | 移植自 ShaderGradient 的噪声褶皱平面，缓慢起伏；Dusk 淡紫与桃色，Ocean 雾蓝沙丘轮廓，Sage 灰绿 |
| Dithering       | Paper Shaders 的点阵漩涡，缓慢旋转与偏移；Orb 变体为蓝色 4×4 点阵球体                          |
| Fluted Glass    | Paper Shaders 的棱纹玻璃滤镜，折射 Paper 的花卉示例照片，棱纹缓慢往复滑动；夜间照片调暗偏冷    |
| Pixel Field     | 自研像素网格，噪声经有序抖动成形，格子随密度缓慢胀缩；指针带柔和光斑，点击产生淡涟漪           |
| Data Pixel Arc  | ThreeUI 的翡翠像素弧线，流光与鼠标控制起伏                                                     |

日夜配色由设置切换。设置小缩略图来自真实渲染截图；加载与降级使用 HTML/CSS 配色。背景卡片只响应点击选择；固定模式选择单个效果，随机池至少保留一个候选。卡片下方是动效档位（静 / 柔 / 活，默认柔）；有固定变体或隐藏变体时，再分别显示“取消固定”和“全部恢复”两行。框架来源与适配细节见 `shaders.md`。

底栏在设计稿材质上增加 SVG 边缘折射，中心文字和图标保持清晰；菜单与设置保留磨砂材质。折射算法与方向高光自行实现，详见 `liquid-glass-research.md`。它是光学近似，不是完整物理光线追踪。

右下角来源品牌名链接当前背景官方页面。默认只显示来源名的淡色文字（透明度 55%），没有玻璃底，也不显示变体名；悬浮或键盘聚焦时显示完整玻璃胶囊、变体名，以及“不再显示”、固定和换一张三个按钮。“不再显示”把当前变体加入隐藏列表并立即换下一张；它是随机池里最后一个可见变体时不出现。固定后每次打开都显示这个变体，换一张按钮隐藏，静止时只留一枚淡色图钉提示。固定期间不显示“不再显示”，需先取消固定。触屏设备不能悬浮，始终显示完整胶囊。随底部控件唤醒和隐藏。

设置中的候选书签保留 Chrome 原始文件夹与顺序，目录可折叠；搜索自动展开匹配路径，已有收藏保留在原目录并显示勾选状态。常用书签与系统书签入口分别可隐藏；只隐藏入口，不删除数据。
