# 设计实现

视觉来源为下载目录中 01–07 开头的七个 ZIP，完整解压到 `design/reference/01` 至 `07`。原始 HTML、支持文件和 vendor 文件保持原样，不进入生产扩展。

| 设计稿                         | 实现                                                                                                     |
| ------------------------------ | -------------------------------------------------------------------------------------------------------- |
| 01 空闲 · 白天                 | 暖白底、低对比慢速背景，空闲时隐藏全部控件                                                               |
| 02 空闲 · 黑夜                 | 深色背景及相同的空闲逻辑                                                                                 |
| 03 鼠标移动 · 按钮浮现         | 底部居中常用书签与全部书签双按钮胶囊，距底 36 px；左下角独立设置按钮，34 px 按钮、4 px 内边距、2 px 间距 |
| 04 悬浮星标 · 展开常用书签     | 星标悬浮展开常用书签，使用已保存的收藏顺序                                                               |
| 05 全部书签 · 级联悬浮菜单     | 书签栏内容为一级，非空其他根文件夹置末尾，递归悬浮菜单、目录计数与边缘避让                               |
| 06 设置 · 常用书签、背景与外观 | 960 × 640 双栏玻璃面板，收藏搜索/增删/排序，上限 10，效果选择、随机池、主题与隐藏延迟                    |
| 07 组件与内置效果 · 白天 黑夜  | 日夜材质、36 px 书签图标、默认/悬浮/激活状态、背景选择与扩展效果                                         |

日间底色 `#ECE9E1`，文字 `#1F1E1B`，玻璃白色 42%，边框白色 75%。夜间底色 `#0F1013`，文字 `#F4F2EC`，玻璃深色 50%，边框白色 16%。面板包含模糊、饱和度、边缘高光、阴影和静态颗粒。字体使用本地 Space Grotesk，中文使用系统无衬线字体。

胶囊使用两个图标按钮。键盘操作时显示控件并保留焦点，鼠标离开弹层后关闭；悬浮跨越菜单间隙有延迟容错。窄屏导航保持居中并距底 40 px，设置距左 24 px，来源胶囊位于右下方第二行以避免重叠，设置转为单列纵向滚动，菜单按可用空间翻转。

## 背景

| 效果            | 图形与运动                                                        |
| --------------- | ----------------------------------------------------------------- |
| Grain Gradient  | Paper Shaders 的颗粒渐变，持续流动并随鼠标偏移                    |
| Dithering       | Paper Shaders 的点阵漩涡，缓慢旋转与偏移                          |
| Pixel Field     | 自研像素网格，噪声经有序抖动成形，移动与点击产生涟漪              |
| Data Pixel Arc  | ThreeUI 的翡翠像素弧线，流光与鼠标控制起伏                        |
| Shader Gradient | 官方 Halo / Plane、Pensive / Sphere、Mint / Water；每轮不重复随机 |
| CRT Terminal    | ThreeUI 复古终端，逐字显示、扫描线、磷光与指针反光                |

日夜配色由设置切换。CRT 保留暗色显像管，日间用琥珀色、夜间用绿色。设置小缩略图来自真实渲染截图；加载与降级使用 HTML/CSS 配色。背景卡片只响应点击选择；固定模式选择单个效果，随机池至少保留一个候选。框架来源与适配细节见 `shaders.md`。

底栏在设计稿材质上增加 SVG 边缘折射，中心文字和图标保持清晰；菜单与设置保留磨砂材质。折射算法与方向高光自行实现，详见 `liquid-glass-research.md`。它是光学近似，不是完整物理光线追踪。

右下角来源品牌名链接当前背景官方页面，使用小玻璃胶囊，文字默认透明度 85%，悬浮与键盘焦点时 100%；随底部控件唤醒和隐藏。

设置中的候选书签保留 Chrome 原始文件夹与顺序，目录可折叠；搜索自动展开匹配路径，已有收藏保留在原目录并显示勾选状态。常用书签与系统书签入口分别可隐藏；只隐藏入口，不删除数据。
