# 磨砂玻璃

底栏、左下角设置按钮与右下角来源胶囊使用 CSS `backdrop-filter: blur(3px) saturate(1.12)`。模糊只作用于控件背后的背景，图标和文字保持清晰。

日间底色不透明度为 12%，夜间为 20%；CRT 背景上的控件使用 24% 深色底。控件渐变高光最高为 8%，以保留背后颜色与轮廓。边框、内阴影和柔和渐变提供边缘高光，不使用 SVG 折射或动态位移纹理。

收藏浮层使用面板底色与 24 px 模糊；书签菜单和设置面板保留各自的磨砂参数。

控件淡出时保持相同材质，700 ms 淡出结束后隐藏；键盘聚焦会立即恢复可见性。系统请求减少透明度时改用实色背景。
