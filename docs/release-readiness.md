# 0.5.0 发布检查

检查日期：2026-10-08。代码已在 `optimize/full-pass` 分支完成；尚未上传、提交或发布扩展。

## 当前验证

- 变更范围：统一变体注册表；Pixel Blast 换成原创的 Pixel Field；纯 rAF 帧循环和自适应帧率；效果切换交叉淡化；上下文丢失恢复；Canvas 2D 变体改为着色器；Radix 换成 Base UI，书签菜单懒加载；控件按背景明暗配色；首屏缓存；乐观保存；根级错误边界；MIT 许可证、Oxlint、oxfmt 与 CI。
- manifest 权限仍为 bookmarks/storage/favicon；新增 `minimum_chrome_version: 111`，CSP 增加 `connect-src 'self'`。
- 存储迁移：旧的 Shader Gradient 随机队列 `shader-gradient:shuffle:v1` 首次抽取时并入变体队列后删除；收藏改存 `{id, url}`，首次写入 v2 时清理 `favorite:v1:*`。迁移有单元测试，尚未做 0.4.1 → 0.5.0 的覆盖升级实测。
- `pnpm check` 通过：Oxlint、oxfmt 检查、类型检查、14 个文件共 131 项测试、生产构建及产物校验。
- 预览页与生产扩展实测：49 个变体 × 日/夜在 1440 × 900 下均为 live 渲染，控件可读，页面错误为 0；启动时主题与语言在首次绘制前写入；设置、书签菜单（鼠标与键盘）、首次提示、空收藏、交叉淡化、超宽屏覆盖均通过。
- 安装包 `shader-tab-0.5.0-chrome.zip` 约 621 KB；首屏入口约 243 KB（预算 265 KB）；Three.js 只由 Shader Gradient 懒加载；22 个实际模块依赖的许可证清单随包提供。
- 未覆盖：0.4.1 → 0.5.0 覆盖升级、电池与窗口失焦降帧的真机验证、跨操作系统、低配设备、超大书签库。

## 提交 0.5.0 前

- 用独立测试 Chrome 从 0.4.1 覆盖升级到 0.5.0，确认扩展 ID、收藏、偏好和随机队列保留。
- 按新界面重拍商店截图（含 Pixel Field 与新的设置面板）。
- 隐私权实践披露无需变更（权限与数据处理未变），提交前复核一次。

# 0.4.1 发布检查

检查日期：2026-09-21。代码可进入小范围 Beta；Chrome Web Store 提交资料尚未齐全。本次未上传、提交或发布扩展。

## 当前验证

- 0.4.1 将扩展管理页、八语名称与标签页标题统一为 `Shader Tab`；无权限、依赖或存储键变更。

- `pnpm check` 通过：类型检查、13 个文件共 78 项测试、生产构建及产物校验。
- 支持简体中文、繁体中文、英文、日文、韩文、法文、德文、西班牙文。默认跟随浏览器，手动选择本地保存；语言包按需加载，无新增依赖。
- 0.4.0 独立临时 Chrome 实测八语切换、1440/390/320 px 共 24 组设置布局、离线语言加载、刷新持久化、收藏名称和排序保留、同页背景画布和变体保留。16 个本地政策/许可页及其内部链接均通过，未发现 JavaScript 运行错误。
- 同目录从 0.3.10 覆盖升级到 0.4.1，并重启独立测试 Chrome：扩展 ID、常用书签、主题及收藏展示均保留。
- ZIP 与生产目录逐文件核对。大小、文件数与 SHA-256 见 `artifacts/release-0.4.1.json`。安装包约 605 KB，首屏入口约 316 KB，低于 340 KB 原始 JS 预算。
- manifest 权限仍仅 bookmarks/storage/favicon；运行代码、shader、字体、图标和翻译本地打包。53 个实际模块依赖的许可证清单及内嵌代码补充声明随包提供。
- 0.3.13 的生产依赖公告扫描检查 77 个依赖，未报告已知漏洞；0.4.0 未改变依赖，未重复联网扫描。此记录不代表全面安全审计，也不自动覆盖依赖内部预打包代码。
- 此前已覆盖背景变体、帧率与后台 GPU 释放；本次未重复全部变体，未做跨操作系统、低配设备、超大书签库或各语言母语者审校。

证据：`artifacts/locales/`、`artifacts/upgrade-0.3.10-to-0.4.1.json`、`artifacts/release-0.4.1.json`。

1. 托管公开可访问的 HTTPS 隐私政策，并填入商店后台。现有本地政策文件不能替代公开网址。
2. 制作并核对商店素材：128 px 图标已随包提供；440×280 RGB 宣传图已生成，见 `artifacts/store-assets/shader-tab-promo-440x280-v1.png`。尚需至少一张 1280×800 或 640×400 的正式截图。
3. 在开发者后台完成账户要求、单一用途、权限理由、数据披露及分发设置。资料草稿见 `store-submission.md`；后台状态尚未核验。

要求依据：[商店发布流程](https://developer.chrome.com/docs/webstore/publish)、[隐私字段](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)、[图像规格](https://developer.chrome.com/docs/webstore/images)。

- 当前目录尚未纳入 Git；建立版本管理和持续集成，保留可回退的源码与构建记录。
- 增加收藏/设置导出导入。当前数据本地保存，卸载会删除，不能承诺卸载重装后恢复。
- 补 Windows、低配 GPU 与大书签库验证；透明控件的无障碍对比度仍需人工检查。

收藏消失已由用户确认发生在先卸载再安装之后；这不等同于同一扩展的正常更新会清空收藏。README 已明确覆盖原目录、刷新扩展的更新步骤。
