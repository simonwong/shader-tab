# 0.7.0 发布检查

检查日期：2026-10-22。已生成安装包 `.output/shader-tab-0.7.0-chrome.zip`，尚未上传。

## 自 0.6.0 的变更

- 背景：新增 9 个 Paper 类别（Mesh Gradient、Warp、Simplex Noise、Perlin Noise、Neuro Noise、Dot Orbit、Smoke Ring、God Rays、Water），共 14 种变体，现为 15 类 42 种。`paper.ts` 改为每个 shader 一项表格配置。
- 随机池：保存时同时写入 `preference:v1:removedEffects`（用户移出的类别）。0.6.0 保存过的随机池升级后自动加入新类别，用户移出过的类别不加回；更新后仍开着的旧版本标签页写入随机池，也不会让新类别丢失。
- 常用书签：新增“平铺在底栏”布局（`preference:v1:favoritesLayout`），老用户默认仍为星标托盘；窗口宽度不够时退回托盘。底栏等偏好、收藏和书签树读完才挂载，平铺用户不再看到首帧跳变。
- 首次引导：全新安装显示两步卡片，选择收藏布局，没有收藏时可从书签栏一键导入最多 10 个。
- 构建检查：首屏预算改为入口加静态导入的分块（当前 258,555 字节），并断言首次引导为动态导入、每个类别都有日夜缩略图。
- 文案：单个书签的导入按钮用单数；德语统一用 Sie；法、德两语缩短“稍后”按钮。

## 当前验证

- `pnpm check` 通过：Oxlint、oxfmt 检查、类型检查、20 个文件共 185 项测试、生产构建及产物校验。
- 安装包 435,537 字节、103 个文件，与生产目录逐文件一致；首屏 JS 258,555 字节（入口 237,015 字节加两个预加载分块，预算 265 KB）。SHA-256 见 `artifacts/release-0.7.0.json`。
- manifest 版本 0.7.0，权限仍为 bookmarks/storage/favicon，CSP 未变，无远程资源。
- `pnpm review:variants`：42 种变体日夜共 84 组 live 渲染、单类随机、窄屏设置和减少动态效果通过。`review-motion.mjs` 对 14 个新变体日夜实测均在动效上限内。
- 独立临时 Chrome 实测生产包：引导三种结束方式、平铺底栏的键盘与宽度回退、首帧（6 个收藏，底栏在 21–49 ms 首次出现即为平铺）、真实 0.6.0 包原地升级到 0.7.0（收藏保留、随机池 14/15、移出 Water 后不回来、模拟旧标签页写入后新类别仍在）、设置三种尺寸日夜无溢出，控制台无错误。截图见 `artifacts/release-qa/`。
- 未覆盖：`perf:measure`；跨操作系统、低配设备、超大书签库。

## 提交 0.7.0 前

- 上传安装包，替换英文和简体中文详细描述，见[商店提交资料](store-submission.md)。商店截图沿用 0.6.0 素材，内容仍与功能一致，未展示平铺布局。
- 隐私权实践披露无需变更（权限与数据处理未变）。

# 0.6.0 发布检查

检查日期：2026-10-14。已生成安装包 `.output/shader-tab-0.6.0-chrome.zip`，尚未上传。上一个记录为已发布的版本是 0.4.1；0.5.0 的发布检查记录为未上传。

## 自 0.5.0 的变更

- 背景：移除 CRT Terminal，已存的选择迁移到 Predictive Arc；Shader Gradient 改为原生 WebGL 移植（Dusk、Ocean、Sage），three.js、react-three-fiber 和 `@shadergradient/react` 不再打包；新增 Fluted Glass；Pixel Field 降噪。现为 6 类 28 种变体。
- 动效：新增静 / 柔 / 活三档，默认柔；静档不响应指针。
- 控件：指针只在屏幕底部附近时唤醒控件；dock 悬停 140 ms 打开面板；dock、设置按钮和来源标签改用液态玻璃（仅 Chrome，其他环境为磨砂玻璃）。来源标签静止时为淡色文字。
- 变体：来源标签可固定、切换、隐藏当前变体，设置中可取消固定和全部恢复；类别按可见变体数的平方根加权抽取。连续点击来源标签按钮时，按钮位置保持不变。
- 依赖：Hugeicons 免费图标升至 4.3.5，修复大小写敏感文件系统上的构建。
- 内部：存储、背景选择和 WebGL 挂载各收拢到一个模块，存储格式和锁名不变。

## 当前验证

- `pnpm check` 通过：Oxlint、oxfmt 检查、类型检查、18 个文件共 152 项测试、生产构建及产物校验。
- 安装包 404,895 字节、82 个文件，与生产目录逐文件一致；首屏入口 253,292 字节（预算 265 KB）。SHA-256 见 `artifacts/release-0.6.0.json`。17 个实际模块依赖的许可声明随包提供。
- manifest 权限仍为 bookmarks/storage/favicon，`minimum_chrome_version` 111，CSP 含 `connect-src 'self'`。
- 独立临时 Chrome 以英文界面加载生产构建，收藏栏、书签菜单、设置面板、来源标签悬停和夜间主题均正常显示（商店截图过程）。
- 来源标签按钮：预览页用真实鼠标连点「换一张」6 次、固定与取消固定各 1 次，按钮坐标不变；移出后宽度恢复。
- 未覆盖：0.4.1 → 0.6.0 覆盖升级实测；本次未重跑 `review:variants`、`perf:measure` 和 `review-motion.mjs`；跨操作系统、低配设备、超大书签库。

# 0.5.0 发布检查

检查日期：2026-10-08。代码已在 `optimize/full-pass` 分支完成；尚未上传、提交或发布扩展。

## 当前验证

- 变更范围：统一变体注册表；Pixel Blast 换成原创的 Pixel Field；纯 rAF 帧循环和自适应帧率；效果切换交叉淡化；上下文丢失恢复；Canvas 2D 变体改为着色器；Radix 换成 Base UI，书签菜单懒加载；控件按背景明暗配色；首屏缓存；乐观保存；根级错误边界；MIT 许可证、Oxlint、oxfmt 与 CI。
- manifest 权限仍为 bookmarks/storage/favicon；新增 `minimum_chrome_version: 111`，CSP 增加 `connect-src 'self'`。
- 存储迁移：旧的 Shader Gradient 随机队列 `shader-gradient:shuffle:v1` 首次抽取时并入变体队列后删除；收藏改存 `{id, url}`，首次写入 v2 时清理 `favorite:v1:*`。迁移有单元测试，尚未做 0.4.1 → 0.5.0 的覆盖升级实测。
- `pnpm check` 通过：Oxlint、oxfmt 检查、类型检查、14 个文件共 131 项测试、生产构建及产物校验。
- 预览页与生产扩展实测：49 个变体 × 日/夜在 1440 × 900 下均为 live 渲染，控件可读，页面错误为 0；启动时主题与语言在首次绘制前写入；设置、书签菜单（鼠标与键盘）、首次提示、空收藏、交叉淡化、超宽屏覆盖均通过。
- 安装包 `shader-tab-0.5.0-chrome.zip` 约 621 KB；首屏入口约 243 KB（预算 265 KB）；Three.js 只由 Shader Gradient 懒加载；22 个实际模块依赖的许可证清单随包提供。
- 未覆盖：0.4.1 → 0.5.0 覆盖升级、电池与窗口失焦降帧的真机验证、跨操作系统、低配设备、超大书签库。
