# SHADER TAB 品牌素材

- `shader-tab-icon-master.png`：内置 image_gen 从已选 03 方案提取的透明图形母版，无文字。
- `shader-tab-logo-uppercase.png`：已选的全大写完整 Logo，保留原始浅色背景。
- `../public/icon/{16,32,48,128}.png`：由图形母版等比缩小的透明 PNG；用于扩展 manifest 和页面 favicon。
- `generation.json`：图形提取提示词、工具和已采用的字标文件。

图形图标用于浏览器小尺寸入口；完整 Logo 用于项目文档和品牌展示。小图标不添加字标。大尺寸品牌原图不进入扩展包。

图标规格依据：[Chrome Manifest Icons](https://developer.chrome.com/docs/extensions/reference/manifest/icons)。
